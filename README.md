# Airline_Analysis
Interactive PowerBi dashboard for airline performance and KPI analysis
**Tools used **: 
Power BI ,Excel,Sql
**KPIs ANALYZED Using Power bi** :
Total Passengers
Load Factor%
Total Flights
Distance Travelled
Passenger Trends
**Features ** :
Interactive Filters
KPI Cards
Bar Charts
Pie Charts
Trend Analysis
**Excel** :
For complex time_series data modeling
**MYSQL**:
For relational data mapping and optimizing queries
